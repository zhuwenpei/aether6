4) Direct same-state comparison against 3.7.4 baseline
-----------------------------------------------------
Using the same synthetic 58 m/s dry-air-collapse state:
3.7.4 dry core mean        = 45.47 mm/h
3.7.5 dry core mean        = 17.12 mm/h
3.7.4 >=24 mm/h fraction   = 0.606
3.7.5 >=24 mm/h fraction   = 0.239
3.7.4 dry core max         = 188.1 mm/h
3.7.5 dry core max         = 55.5 mm/h

This specifically catches the reported failure mode: 3.7.4 could make a dry-intruded storm's
biased convective lobe substantially wetter/stronger than the intact storm; 3.7.5 reverses that
relationship and makes the dry-intruded inner core weaken as a whole.
