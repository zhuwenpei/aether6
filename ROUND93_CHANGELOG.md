# ROUND93 CHANGELOG — AETHER 6.0.16

## 1. Equal-intensity wind-pressure products now retain small pressure variability
- `TropicalCycloneVortex.ts` adds a deterministic, continuous ±~1 hPa product-only structural/time perturbation to the vortex central pressure used by the synoptic product.
- The live `Engine.pmin` state is not rewritten. The perturbation is used consistently by the product pressure gradient, so equal-Vmax frames are no longer forced into an identical pressure bowl.

## 2. Quick Tools: user-forced cold-water patch
- Added `冷水区` under the typhoon-status quick tools.
- Temperature slider: `0–30°C`, 0.5°C increments.
- Duration slider: `0–120 h` simulation time, 0.5 h increments; state supports up to 240 h if later entered programmatically.
- During the scheduled interval the cyclone-center SST is the requested value and OHC is recalculated from that SST. Existing cold-water / convection / intensity memory then handles weakening and post-event recovery.
- Cold-water event fields are persisted into hourly/history and forecast seed snapshots and are removed by `取消所有惩罚`.

## 3. Stronger storms have a more centered, round eye in wind products
- Added an intensity-dependent mature-eye symmetry gate.
- Inner-core pressure ellipticity, translation-induced eye displacement and shear asymmetry are progressively suppressed as Vmax rises.
- Outer-core / ET asymmetry remains available, so this does not force the whole storm to become circular.

## 4. Circulation-size target range: 0 km to no hard upper limit
- UI numeric input minimum changed from 150 km to 0 km and has no maximum.
- Slider minimum is 0 and its maximum expands dynamically when the current reference exceeds the normal 500 km working range.
- `CirculationSizeTransition` and Engine preference scaling now accept 0.
- A 0 km reference can genuinely collapse R7/R10/R12 to zero; the old 15 km floor and 550 km general cap no longer override an explicit user target.

## 5. Product coastline coverage extended 30° farther east
- Added `public/data/product_land_wide_v3.geojson`.
- East edge is now 110°W / 250°E, versus 140°W / 220°E in v2.
- The added 140°W–110°W belt uses bundled GSHHS intermediate coastline geometry.

## 6. Wind-pressure map country borders removed
- Added `public/data/product_coastline_only_v4.geojson`, generated by dissolving the high-detail country polygon plate so shared admin-0 borders disappear, then merging the new eastward coastline extension.
- `SynopticWindPressureMap.ts` now draws this coastline-only plate; it no longer imports or renders `productCountriesGeoJson`.
